# Common Git Commands

## cd (Change Directory)
Allows the user to change to another directory/folder via the terminal.
> cd [DIRECTORY_NAME] 

If you want to go back to the previous/parent directory, you can add two sequential periods.
> cd ..

In order to get to the root directory, you just type cd.
> cd

## mkdir (Make Directory)
Allows user to create a new directory/folder in the current location.
> mkdir [DIRECTORY_NAME]

## touch
Allows user to create a file within the terminal.
> touch [FILENAME.file_type]
>> e.g. *touch README.md*
