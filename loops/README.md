# Loops

## Types of loops in C++

In C++ there three different types of loops with:
1. While Loops
2. For Loops
3. Do-While Loops

The the three above mentioned loops essentially perform the same task, to loop over a certain section
of code till a condition is no longer considered true. For the three loops, you can convert each loop
into one another, e.g. converting a for-loop to a while-loop and vice-versa.
